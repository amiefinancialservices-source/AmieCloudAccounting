# Amie Cloud Accounting

Cloud-based accounting software designed for Canadian small businesses, accountants, and bookkeepers.

## Planned Features
- Customer and supplier management
- Invoicing and expense tracking
- Double-entry bookkeeping
- Chart of accounts
- GST/HST calculations and reports
- Profit and loss statements
- Balance sheets
- Trial balance reports
- Secure multi-company access

## Target Market
Canadian small businesses, accountants, and bookkeepers.

## Project Status
Initial setup and development planning.
